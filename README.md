# GITARTHA
#GITARTHA Bhagavad Gita Project With 18 Chapters

Gitartha – Bhagavad Gita Website
Project Overview
Gitartha is a web-based project designed to provide information about the 18 chapters of the Bhagavad Gita through a simple and user-friendly interface.

Features
Welcome page
Sidebar navigation for all 18 chapters
Chapter-wise pages
Related images
Easy navigation
Responsive and user-friendly design
Technologies Used
HTML
CSS
JavaScript
